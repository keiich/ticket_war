# Ticket War Clicker

指定時刻に、対象サイトのサーバー時計に合わせてミリ秒精度でボタンをクリックする userscript / ブックマークレットを生成する静的サイト。

- `index.html` … 設定画面・スクリプト生成・精度テスト
- `engine.js` … 対象ページ上で動くクリックエンジン

## 仕組み
1. 対象サーバーへ HEAD リクエストを位相をずらして複数回送り、`Date` ヘッダの秒の境目から時差を ±数十ms で推定
2. 発射2.5秒前に接続を温める (keep-alive)
3. 直前まで setTimeout で待ち、最後の約40msはビジーウェイトで精密に待機
4. 時刻になったらクリック。ボタンがまだ無い/無効なら MutationObserver + 4ms ポーリングで出現した瞬間にクリック
5. リロードモード: 時刻にリロードし、再読込後のページで即ボタンを探してクリック (userscript のみ)

静的ファイルのみなので Vercel にそのままデプロイできます。
