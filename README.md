# Ticket War Clicker

発売時刻ぴったりに、チケットサイトのボタンを自動で押す Tampermonkey スクリプトを作る静的サイト。

- `index.html` … 手順ガイド・設定・スクリプト生成・🎯ボタン調査ブックマークレット・精度テスト
- `engine.js` … チケットサイト上で動くクリックエンジン

## 仕組み
1. サイトへ HEAD リクエストを「秒の切り替わり」に合わせて送り、`Date` ヘッダから時差を数ms〜数十msで推定（早すぎないよう遅い側に合わせる）
2. 発射2.5秒前に接続を温める (keep-alive)
3. 直前まで setTimeout で待ち、最後の約40msはビジーウェイトで精密に待機
4. 発売時刻に再読み込み（またはその場で）→ 登録したボタンを順番に押す。ページが切り替わっても localStorage で次のステップを引き継ぐ
5. ボタン1が出ていなければ出るまで再読み込み。ボタンは MutationObserver + 4ms ポーリングで出現した瞬間に押す

静的ファイルのみなので Vercel にそのままデプロイできます。
