⚡ Ticket War Clicker

発売時刻ぴったりに、チケットサイトのボタンを自動で押します。ブラウザ拡張「Tampermonkey」で動かします。PC（Chrome / Edge / Firefox）用です。

しくみ

チケットサイトは、最初に開くページ（公演一覧など）に「申込」ボタンがあるとは限りません。そこでこのツールでは、押すボタンを順番に何個でも登録できます。

発売時刻→ページを再読み込み→ボタン1（例: 公演の「詳細」）→次のページ→ボタン2（例: 「申込」）→…ここから手動

ページが切り替わっても、スクリプトが「次はボタン何番か」を覚えていて続きを押します。

1Tampermonkey を入れる（最初の1回だけ）

  1. tampermonkey.net を開き、自分のブラウザ用のストアから追加
  2. Chrome / Edge の場合: 右上のパズル型アイコン → Tampermonkey の「︙」→「拡張機能を管理」→ 「ユーザー スクリプトを許可する」をオン（無い場合は、拡張機能ページ右上の「デベロッパー モード」をオン）
これをやらないとスクリプトが動きません。

2🎯 ボタン調査ツールを用意する

下のボタンをブックマークバーへドラッグして登録します（ブックマークバーが無ければ Ctrl+Shift+B で表示）。

🎯 ボタン調査

チケットサイトでこのブックマークを押してから、調べたいボタンをクリックすると、そのボタンの「CSSセレクタ」（ボタンの住所のようなもの）が表示＆コピーされます。調べている間はボタンを押してもページは移動しません。

3申込までの流れを調べる

  1. チケットのページ（例: 公演一覧）を開く
  2. 申込ページにたどり着くまでに押すボタンを順番にメモする（例: ①公演の「詳細」→②「申込」）
  3. それぞれのページで 🎯 を押し、そのボタンをクリック → 出てきたセレクタを下の設定に貼る

発売前はまだ「申込」ボタンが無いことが多いです。その場合は、同じサイトで今発売中の別の公演で同じ位置のボタンを調べるか、セレクタの代わりにボタンの文字（例: 申込）を入れてください。

4設定する

このサイト内のすべてのページでスクリプトが動きます。

各ボタンは「CSSセレクタ」か「ボタンの文字」のどちらかを入れます（両方入れるとセレクタ優先）。文字は部分一致で、「|」区切りで複数候補を書けます（左ほど優先）。「申込方法について」などの案内リンクは自動で除外します。

詳細設定（ふつうは触らなくてOK）
発売時刻にボタンが自動で出てくるサイトなら「その場で」。
早すぎると「発売前」の画面になるので 0 推奨。

5スクリプトを Tampermonkey に登録

  1. ↑「スクリプトをコピー」を押す
  2. ブラウザ右上の Tampermonkey アイコン →「新規スクリプトを作成」
  3. 最初から書いてある文字を全部消して（Ctrl+A → Delete）、貼り付け（Ctrl+V）
  4. Ctrl+S で保存
設定を変えたときは、コピーし直して同じスクリプトに上書き保存してください（古いスクリプトが残っていると二重に動きます）。
スクリプトの中身を見る

6動いているか確認（前日までに）

  1. チケットサイトを開く
  2. 画面の右下に黒い箱（⚡ticket_war と時刻・残り時間）が出ていれば成功
  3. 出ない → 手順1の「ユーザー スクリプトを許可する」と、手順4のURLを確認

7発売当日

  1. 発売5分前までにログインを済ませ、ボタン1が出てくるページを開いて待つ
  2. チケットサイトのタブは1つだけにする（複数あると全部が再読み込みします）
  3. 右下の黒い箱に「目標 ○○:○○:00.000」と出ていれば準備OK
  4. そのタブを前に出したまま、何も触らず待つ（別タブに切り替えない・PCをスリープさせない）
  5. 発売時刻に再読み込み → ボタン1 → ボタン2 … と自動で押します（ボタン1が出ていなければ出るまで再読み込み）
  6. 黒い箱に「全ステップ完了」と出たら、そこからは自分で操作（枚数・支払い方法など）

8終わったら

Tampermonkey アイコン → このスクリプトのスイッチをオフ（または削除）。
